# 经营小账本

面向个体工商户的自托管经营流水应用，使用 React、Express 和 SQLite。账目、密码校验和数据库都留在自己的设备上。

## 功能

- 记录收入和支出，覆盖日常开支、交通、人情收支、进货、出货、房租水电、工资等分类。
- 可在“分类管理”中添加收入或支出分类，并通过拖动或箭头调整顺序；已有账目使用的分类不能删除。
- 可选择当前日期以前的任意日期补录、编辑或删除历史流水，并按月份回看收支、结余和明细。
- 按收支类型筛选，按分类和备注搜索；支持将当前筛选结果导出为 CSV。
- SQLite 数据库保存在 `./data/ledger.sqlite`，容器重建不会清空账目。
- 支持用户注册和登录，每个账号拥有独立账目；注册密码至少 8 位并包含字母和数字，使用 scrypt 哈希保存，登录状态使用 HttpOnly、SameSite Cookie。
- 可修改当前账号的分类名称和个体户名称；账本显示为“个体户名称 小账本”，分类改名会同步更新该账号的历史账目。
- 记账时可直接添加多张任意格式凭证，单张不超过 10 MB；编辑流水时可查看并点击打开已添加凭证。凭证保存在 `data/receipts`，也可在流水凭证管理中修改文件名、单独打开或下载、删除。

## 飞牛 NAS 部署

1. 将项目目录放到 NAS 上，进入该目录。
2. 复制 `.env.example` 为 `.env`，将 `APP_SECRET` 替换为至少 32 位随机字符串。若从旧版升级，保留原 `.env` 中的 `APP_PASSWORD`，并在首次注册时输入旧版账本密码；完成认领后可移除该配置。
3. 在飞牛 Docker 项目中选择该目录及 `compose.yaml` 构建并启动；或在支持 Compose 的终端运行：

	```sh
	docker compose up -d --build
	```

4. 在局域网浏览器打开 `http://NAS地址:3080`。如需更换端口，修改 `.env` 中的 `PORT`。

数据保存在项目下的 `data` 目录。升级后首次注册的账号需验证旧版账本密码并继承现有账目和分类，后续注册账号彼此隔离。当前开放注册，任何能访问服务的人都可以创建自己的账号；若部署到公网，请通过防火墙或反向代理限制访问。建议升级前备份 `data` 目录。请勿将未启用 HTTPS 的服务端口直接暴露到公网；通过 HTTPS 反向代理访问时，将 `COOKIE_SECURE=true`。

## 本地开发

安装 Node.js 22。设置 `APP_SECRET` 环境变量后，在一个终端运行 `npm run dev:server`，另一个终端运行 `npm run dev`，打开 Vite 输出的地址。首次打开页面后注册账号，开发数据存放于项目的 `data` 目录。
